# Лабораторная работа №3: Классификация и метрики классификации
## Цель работы
1. Освоить базовые методы решения задач классификации.
2. Научиться использовать библиотеки scikit-learn для построения и обучения моделей.
3. Разобраться в ключевых метриках классификации (Accuracy, Precision, Recall, F1, ROC-AUC).
4. Научиться интерпретировать результаты классификатора и сравнивать модели по качеству.

Рекомендуется выполнять задания по очереди.

## Локальный запуск тестов

Github Classroom дает ограниченное количество минут на тестирование отправок студентов, поэтому чтобы не сжигать их лишний раз, перед отправкой решения на GitHub просьба проверить его локально (иначе потом тестирование будет проходить гораздо дольше). Для этого в репозитории предусмотрены скрипты для разных операционных систем: 

### Windows

Есть два варианта запуска: 

1. Двойным кликом по файлу run_tests.bat
2. Через командную строку

```
run_tests.bat
```

### Linux/macOS

1. Сделайте скрипт исполняемым (только при первом запуске):

```
chmod +x run_tests.sh
```

2. Запустить скрипт:

```
./run_tests.sh
```

## Вопросы для самоподготовки
Вопросы для самоподготовки
1. В чем заключается задача классификации и чем она отличается от задачи регрессии?
2. Как вычисляются Precision, Recall, F1-score и в чём смысл каждой метрики? Почему Accuracy не всегда подходит как основная метрика?
3. Что такое ROC-кривая и площадь под ней (AUC)? Что такое PR-кривая? Как выбор порога классификации влияет на метрики модели?
4. Как вычислять метрики при многоклассовой классификации? Чем отличаются микро-, макро- и взвешенное усреднение метрик?
5. Что такое дисбаланс классов? Как с ним бороться? Как необходимо учитывать в функции потерь дисбаланс классов при обучении модели?
