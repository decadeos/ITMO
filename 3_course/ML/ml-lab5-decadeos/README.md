## Пара слов об использовании GPU
Использование GPU при выполнении работы на локальной машине приветствуется (кроме AMD).

Что делать, если вы хотите настроить виртуальное окружение, поддерживающее NVIDIA GPU?

Для начала проверьте, что у вас установлены необходимые драйвера. Для этого в терминале (неважно какой системы) выполните команду 

```bash
nvidia-smi
```

Должна появиться информация о текущей (или о текущих) видеокартах, а также версии драйвера. Рекомендуется обновиться до последней версии драйвера NVIDIA, чтобы избежать проблем с установкой torch+cuda. Устанавливать CUDA Toolkit не нужно.

Если `nvidia-smi` выдаёт ошибку, проверьте, что ваша система видит видеокарту NVIDIA. В крайнем случае - переустановите драйвера.

### На Windows+NVIDIA
1. Двойным кликом по файлу `init_venv_gpu.bat`
2. Через командную строку

```bash
init_venv_gpu.bat
```

### На Linux+NVIDIA
1. Сделайте скрипт исполняемым (только при первом запуске):

```bash
chmod +x init_venv_gpu.sh
```

2. Запустить скрипт:

```bash
./init_venv_gpu.sh
```

### На MacOS с чипами M-серии
Очевидно, что чипы M-серии не поддерживают CUDA. Для ускорения нейронных сетей на этих чипах используется Metal Backend, который также представлен в torch.

Чтобы получить возможность использовать GPU на чипах M-серии, выполните шаги аналогично с Linux+NVIDIA, только используйте скрипт `init_venv.sh`


### Что делать, если у меня видеокарта AMD
Рекомендуется использовать Google Colab или Kaggle для обучения. В ином случае действуйте на свой страх и риск.

Если при обучении локально у вас появятся неожиданные ошибки, связанные с AMD GPU, преподаватели-практики вам вряд ли смогут помочь.
