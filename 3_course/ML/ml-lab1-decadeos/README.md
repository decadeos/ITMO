# Лабораторная работа №1: Анализ данных

## Цель работы
1. Освоить работу с pandas для загрузки и обработки данных.
2. Освоить работу с библиотеками визуализации данных (matplotlib/seaborn).

Работу необходимо выполнить в jupyter-блокноте [exercises.ipynb](exercises.ipynb). Рекомендуется выполнять задания по порядку.
