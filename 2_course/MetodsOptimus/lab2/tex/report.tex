\subsection{Реализация методов для численной оценки градиента и гессиана}
\subsubsection{Градиент}

Формула для каждой компоненты градиента с использованием центральной разностной схемы:

\[
\frac{\partial f}{\partial x_i} \approx \frac{f(\mathbf{x} + h\mathbf{e}_i) - f(\mathbf{x} - h\mathbf{e}_i)}{2h}
\]

Где:
\begin{itemize}
	\item $h$ - малый шаг (эпсилон)
	\item $f$ - дифференцируемая функция
	\item $x$ - точка вычисления
	\item $\mathbf{e}_i$ - $i$-й базисный вектор
\end{itemize}

Весь градиент - это вектор таких производных:

\[
\nabla f(\mathbf{x}) \approx \left(
\frac{f(x+h,y)-f(x-h,y)}{2h}, 
\frac{f(x,y+h)-f(x,y-h)}{2h}
\right)
\]
Вот код, который реализует это:

\begin{lstlisting}[language=python, caption={Градиент}]
def numericalGradient(f, x, h=1e-5):
	n = len(x)
	grad = np.zeros_like(x)
	for i in range(n):
		e_i = np.zeros_like(x)
		e_i[i] = h
		grad[i] = (f(x + e_i) - f(x - e_i)) / (2 * h)
	return grad
\end{lstlisting}



\subsubsection{Гессиан}

Мы хотим найти матрицу вторых производных (гессиан) функции $f(x_1, x_2, ..., x_n)$ в точке.

Для этого мы:
\begin{itemize}
	\item Берем маленький шаг $h$ - эпсилон
	\item Смотрим, как меняется функция при небольших изменениях по разным направлениям
	\item Используем комбинации значений функции в соседних точках
\end{itemize}

Мы считаем так:

Для каждой пары переменных $(x_i, x_j)$:

1. Создаем 4 точки, немного меняя $x_i$ и $x_j$:
\begin{itemize}
	\item Точка 1: $x_i + h$, $x_j + h$
	\item Точка 2: $x_i + h$, $x_j - h$
	\item Точка 3: $x_i - h$, $x_j + h$
	\item Точка 4: $x_i - h$, $x_j - h$
\end{itemize}

2. Считаем элемент матрицы по формуле:
\[
H_{ij} = \frac{f(\text{Точка1}) - f(\text{Точка2}) - f(\text{Точка3}) + f(\text{Точка4})}{4h^2}
\]

3. Так как матрица симметричная, $H_{ji} = H_{ij}$

Для функции $f(x,y)$ гессиан будет:
\[
H = \begin{pmatrix}
	\frac{\partial^2 f}{\partial x^2} & \frac{\partial^2 f}{\partial x \partial y} \\
	\frac{\partial^2 f}{\partial y \partial x} & \frac{\partial^2 f}{\partial y^2}
\end{pmatrix}
\]

Вот код:
\begin{lstlisting}[language=python, caption={Гессиан}]
def numericalHessian(f, x, h=1e-5):
	n = len(x)
	hess = np.zeros((n, n))
	for i in range(n):
		for j in range(i, n):x1, x2 = x.copy(), x.copy()
		x1[i] += h; x1[j] += h
		x2[i] += h; x2[j] -= h
		x3, x4 = x.copy(), x.copy()
		x3[i] -= h; x3[j] += h
		x4[i] -= h; x4[j] -= h
		hess[i,j] = (f(x1) - f(x2) - f(x3) + f(x4)) / (4 * h**2)
		hess[j,i] = hess[i,j]
			
	return hess
\end{lstlisting}

\item  \texttt{Комбинация из пары тригонометрических функций}

Возьмем такую функцию: \[
f(x_1, x_2) = \sin(x_1)\cos(x_2) + \sin(x_1 + x_2)
\]
Вот ее реализация:

\begin{lstlisting}[language=python, caption={Тригонометрическая функция}]
def trigFunc(x):
	return sin(x[0]) * cos(x[1]) + sin(x[0] + x[1])
\end{lstlisting}

Ее градиент: 


\[
\nabla f = 
\begin{pmatrix}
	\frac{\partial f}{\partial x_1} \\ 
	\frac{\partial f}{\partial x_2}
\end{pmatrix} 
= 
\begin{pmatrix}
	\cos x_1 \cos x_2 + \cos(x_1 + x_2) \\
	-\sin x_1 \sin x_2 + \cos(x_1 + x_2)
\end{pmatrix}
\]


Его реализация:
\begin{lstlisting}[language=python, caption={Градиент тригонометрической функции}]
def exactGradTrig(x):
	return np.array([
	cos(x[0])*cos(x[1]) + cos(x[0] + x[1]),
	-sin(x[0])*sin(x[1]) + cos(x[0] + x[1])
	])
\end{lstlisting}

Также рассмотрим гессиан:


\[
\nabla^2 f = 
\begin{pmatrix}
	\frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1 \partial x_2} \\
	\frac{\partial^2 f}{\partial x_2 \partial x_1} & \frac{\partial^2 f}{\partial x_2^2}
\end{pmatrix}
=
\begin{pmatrix}
	-\sin x_1 \cos x_2 - \sin(x_1 + x_2) & -\cos x_1 \sin x_2 - \sin(x_1 + x_2) \\
	-\cos x_1 \sin x_2 - \sin(x_1 + x_2) & -\sin x_1 \cos x_2 - \sin(x_1 + x_2)
\end{pmatrix}
\]


Реализация кодом:

def exactHessTrig(x):

	])

\item \texttt{Полином нескольких переменных степени 3}

Вот такую функцию мы выбрали:

f(x_1, x_2, x_3) = x_1^3 + 2x_1^2x_2 - 3x_1x_2^2 + x_2^3 + x_1x_2x_3

Реализация на питоне:

def polyFunc(x):

\end{lstlisting}

Также расчитаем градиент функции и ее гессиан.


\[
\nabla f =
\begin{pmatrix}
	\frac{\partial f}{\partial x_1} \\ 
	\frac{\partial f}{\partial x_2} \\
	\frac{\partial f}{\partial x_3} \\
	
\end{pmatrix} 
= 
\begin{pmatrix}
	3x_1^2 + 4x_1x_2 - 3x_2^2 + x_2x_3 \\
	2x_1^2 - 6x_1x_2 + 3x_2^2 + x_1x_3 \\
	x_1x_2
\end{pmatrix}
\]



\[
\nabla^2 f = 
\begin{pmatrix}
	\frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1 \partial x_2} & \frac{\partial^2 f}{\partial x_1 \partial x_3} \\
	\frac{\partial^2 f}{\partial x_2 \partial x_1} & \frac{\partial^2 f}{\partial x_2^2} & \frac{\partial^2 f}{\partial x_2 \partial x_3} \\
	\frac{\partial^2 f}{\partial x_3 \partial x_1} & \frac{\partial^2 f}{\partial x_3 \partial x_2} & \frac{\partial^2 f}{\partial x_3^2}
\end{pmatrix}
= 
\begin{pmatrix}
	6x_1 + 4x_2 & 4x_1 - 6x_2 & x_2 \\
	4x_1 - 6x_2 & -6x_1 + 6x_2 & x_1 \\
	x_2 & x_1 & 0
\end{pmatrix}
\]

Вот код на питоне для градиента и гессиана:

def exactGradPoly(x):

	3*x[0]**2 + 4*x[0]*x[1] - 3*x[1]**2 + x[1]*x[2],

def exactHessPoly(x):

\item \texttt{Композиция, содержащая exp, ln, arctan и возведение в степень}

Мы взяли такую функцию:

\[
f(x_1, x_2, x_3) = e^{x_1} \ln(1 + x_2^2) + \arctg(x_1 x_3)
\]

Реализация:


\begin{lstlisting}[language=python, caption=Композиция нескольких функций]
def complexFunc(x):
	return exp(x[0]) * log(1 + x[1]**2) + atan(x[0]*x[2])
\end{lstlisting}

Также расчитаем градиент и гессиан для этой функции:

\[
\nabla f =
\begin{pmatrix}
	\frac{\partial f}{\partial x_1} \\ 
	\frac{\partial f}{\partial x_2} \\
	\frac{\partial f}{\partial x_3} \\
	
\end{pmatrix} 
= 
 \begin{pmatrix}
	\frac{z}{x^2 z^2 + 1} + e^x \ln(y^2 + 1) \\
	2 y \frac{e^x}{y^2 + 1} \\
	\frac{x}{x^2 z^2 + 1}
\end{pmatrix}
\]

\[
\nabla^2 f = 
\begin{pmatrix}
	\frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1 \partial x_2} & \frac{\partial^2 f}{\partial x_1 \partial x_3} \\
	\frac{\partial^2 f}{\partial x_2 \partial x_1} & \frac{\partial^2 f}{\partial x_2^2} & \frac{\partial^2 f}{\partial x_2 \partial x_3} \\
	\frac{\partial^2 f}{\partial x_3 \partial x_1} & \frac{\partial^2 f}{\partial x_3 \partial x_2} & \frac{\partial^2 f}{\partial x_3^2}
\end{pmatrix}
= 
\begin{pmatrix}
	-\frac{2 x z^3}{(x^2 z^2 + 1)^2} + e^x \ln(y^2 + 1) & \frac{2 y e^x}{y^2 + 1} & \frac{1 - x^2 z^2}{(x^2 z^2 + 1)^2} \\
	\frac{2 y e^x}{y^2 + 1} & \frac{2 e^x (1 - y^2)}{(y^2 + 1)^2} & 0 \\
	\frac{1 - x^2 z^2}{(x^2 z^2 + 1)^2} & 0 & -\frac{2 x^3 z}{(x^2 z^2 + 1)^2}
\end{pmatrix}
\]

И также код:
\begin{lstlisting}[language=python, caption=Градиент и гессиан композиции нескольких функций]
def exactGradComplex(x):
	return np.array([
	exp(x[0])*log(1 + x[1]**2) + x[2]/(1 + (x[0]*x[2])**2),
	exp(x[0])*(2*x[1])/(1 + x[1]**2),
	x[0]/(1 + (x[0]*x[2])**2)
	])

def exactHessComplex(x):
	h11 = exp(x[0])*log(1 + x[1]**2) - (2*x[0]*x[2]**2)/(1 + (x[0]*x[2])**2)**2
	h12 = exp(x[0])*(2*x[1])/(1 + x[1]**2)
	h13 = (1 - (x[0]*x[2])**2)/(1 + (x[0]*x[2])**2)**2
	h22 = exp(x[0])*(2 - 2*x[1]**2)/(1 + x[1]**2)**2
	return np.array([
	[h11, h12, h13],
	[h12, h22, 0],
	[h13, 0, -2*x[0]**2*x[2]/(1 + (x[0]*x[2])**2)**2]
	])
\end{lstlisting}
\end{itemize}


\subsubsection{Функция оценки точности}

Итак, для начала выберем 3 точки, в которых будем все оценивать:

\begin{align*}
	\mathbf{x}_1 &= \begin{pmatrix} 0.5 & 1.0 & -0.5 \end{pmatrix}, \\
	\mathbf{x}_2 &= \begin{pmatrix} 1.0 & -1.0 & 2.0 \end{pmatrix}, \\
	\mathbf{x}_3 &= \begin{pmatrix} 0.0 & 0.5 & 2.5 \end{pmatrix}.
\end{align*}

\begin{lstlisting}[language=python, caption=Выбор точек]
testPoints = [
	np.array([0.5, 1.0, -0.5]),
	np.array([1.0, -1.0, 2.0]),
	np.array([0.0, 0.5, 2.5])
]
\end{lstlisting}

Далее создадим переменную \texttt{hValues} и запишем туда 50 чисел:

\begin{lstlisting}[language=python, caption=\texttt{hValues} в логарифмическом масштабе]
	hValues = np.logspace(-10, -1, 50)
\end{lstlisting}

Создаёт 50 чисел, равномерно распределённых в логарифмическом масштабе между $10^{-10}$ и $10^{-1}$.

Можно понять это вот так:
\[ h_i = 10^{x_i}, \quad x_i \in [-10, -1] \]

Теперь точно приступим к функции оценки точности:


\begin{lstlisting}[language=python, caption=\texttt{evaluateAccuracy()}]
def evaluateAccuracy():
	results = defaultdict(lambda: ([[] for _ in range(3)], [[] for _ in range(3)]))  # (grad_errors, hess_errors)
	
	functions = {
		'trig': (trigFunc, exactGradTrig, exactHessTrig, 2),
		'poly': (polyFunc, exactGradPoly, exactHessPoly, 3),
		'complex': (complexFunc, exactGradComplex, exactHessComplex, 3)
	}
	
	for name, (func, exactGrad, exactHess, dim) in functions.items():
		for i, x_full in enumerate(testPoints):
			x = x_full[:dim]
			gradErrors, hessErrors = results[name]
			
			for h in hValues:
				numGrad = numericalGradient(func, x, h)
				numHess = numericalHessian(func, x, h)
				
				gradErrors[i].append(np.linalg.norm(numGrad - exactGrad(x)))
				hessErrors[i].append(np.linalg.norm(numHess - exactHess(x)))
	
	return results
\end{lstlisting}

Теперь не кратко по ней пройдемся:

\begin{itemize}

	\item Словарь \texttt{functions} нужен, чтобы там хранились ссылки на имена функций, аналитически вычисленных в пункте~\ref{subsec:methods} градиентов и гессианов для этих функций, а также сюда мы записали размерности функций.
	
	
	\item \texttt{for name, (func, exactGrad, exactHess, dim) in functions.items():} - тут мы проходимся непосредственно по словарю из предыдущего пункта.
	
	\item Далее мы проходимся по нашим \texttt{testPoints} и обрезаем точку до размерности функции \texttt{dim}, это нужно так как у нас есть \texttt{2D} и \texttt{3D} функции. Также в этом \texttt{for} мы достаем списки для хранения ошибок.
	
	\item \texttt{for h in hValues:} - это цикл по всем шагам \texttt{hValues}. Тут мы расчитываем градиент и гессиан в какой-то точке, причем градиент и гессиан берутся уже расчитанные и зависящие от названия функции + тут же мы расчитываем численно написанные градиент и гессиан. Далее мы заполняем массивы норм ошибок.
	
	
	
	
	\end{itemize}

	\subsection{Некоторый способ создания функции}
	
	\texttt{Оля, тут нужна твоя математическая подкованность}
	
    \section{Task. Метод Ньютона}
    Хотим найти минимум функции $f(x)$. На каждой итерации:
    \[
    x_{k+1} = x_k - \alpha (	\nabla^2 f(x_k))^{-1} \nabla f(x_k),
    \]
    где:
    \begin{itemize}
    	\item $\nabla f(x_k)$ — градиент
    	\item $H(x_k)$ — гессиан
    	\item $\alpha$ — шаг (можно брать 1 или подбирать по стратегии) Архимо-Вульфа
    \end{itemize}
    \subsection{Реализация метода}
    
\begin{itemize}
	\item Вычисляем градиент $\nabla f$ и гессиан $\nabla^2 f$ численно
	\item Находим направление $d$ из уравнения $\nabla^2 f \cdot d = -\nabla f$ \\
	(в коде: \texttt{direction = -np.linalg.solve(hessian, grad)})
	\item Выбираем шаг $\alpha$:
	\begin{itemize}
		\item Если \texttt{alpha='wolfe'}, вычисляем $\alpha$ через \texttt{arhim}
		\item Иначе $\alpha = 1$ (чистый метод Ньютона)
	\end{itemize}
	\item Обновляем точку: $x_{k+1} = x_k + \alpha \cdot d$ \\
	\item Повторяем, пока $\|\nabla f\| < \texttt{tol}$
\end{itemize}
	Итак, вот наша реализация этого метода на python:
	
	\begin{lstlisting}[language=python, caption=Метод Ньютона]
def newtonMethod(f, x0, alpha='wolfe', tol=1e-6, maxIter=100, h=1e-5):
	x = np.array(x0, dtype=float)
	history = [x.copy()]
	
	for _ in range(maxIter):
		grad = numericalGradient(f, x, h)
		if np.linalg.norm(grad) < tol:
			break
		
		hessian = numericalHessian(f, x, h)
		direction = -np.linalg.solve(hessian, grad)
	
		if alpha == 'wolfe':
			step = arhim(f, lambda x: numericalGradient(f, x, h), x, direction)
		else:
			step = 1.0
	
		x += step * direction
		history.append(x.copy())
	
	return x, np.array(history)
	\end{lstlisting}
	
	
	\subsection{Тестирование метода на квадратичной функции}
	
	В задании сказано, что нужно взять квадратичные функции из прошлой лабораторной. Мы так и сделаем
	\[
	f(\mathbf{x}) = \mathbf{x}^T A \mathbf{x} + \mathbf{b}^T \mathbf{x}
	\]
	
	\[
	\mathbf{x}^T A \mathbf{x} + \mathbf{b}^T \mathbf{x} = \begin{bmatrix} x_1 & x_2 \end{bmatrix}
	\begin{bmatrix} 2 & 1 \\ 1 & 3 \end{bmatrix}
	\begin{bmatrix} x_1 \\ x_2 \end{bmatrix} + \begin{bmatrix} 1 & -1 \end{bmatrix}
	\begin{bmatrix} x_1 \\ x_2 \end{bmatrix}
	= 2x_1^2 + 2x_1x_2 + 3x_2^2 + x_1 - x_2
	\]
	
	
	\begin{lstlisting}[language=python, caption=Задание функции]
def f(x):
	A = np.array([[2, 1], 
	              [1, 3]])
	b = np.array([1, -1])

	f = lambda x: x.T @ A @ x + b.T @ x
	\end{lstlisting}
